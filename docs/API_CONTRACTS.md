# Block 9A API contracts

Contract inventory prepared before route implementation. Prefix `/api/v1`. JSON response `{data: ...}`; error `{error: {code, message}, requestId}`. UUID IDs, ISO dates, integer minor units as decimal strings. Unknown body/query fields are rejected. No caller-supplied actor, workspace ownership or source metadata. Workspace IDs come from the authorized path, never writable entity bodies.

| Operation          | Method and route                                 | Request                                                                                                              | Response                                   | Authorization / models / transaction / idempotency                                                                                                                                 |
| ------------------ | ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Register           | POST /auth/register                              | fullName, email, password                                                                                            | neutral accepted message                   | Public; User insert, Argon2id; duplicate uses same response, no automatic session                                                                                                  |
| Login              | POST /auth/login                                 | email, password, rememberMe?                                                                                         | safe user                                  | Public; User + AuthSession; opaque HttpOnly cookie; new session each login                                                                                                         |
| Session            | GET /auth/session                                | none                                                                                                                 | user + onboardingComplete                  | Active unexpired session; no tokens or hashes                                                                                                                                      |
| Logout             | POST /auth/logout                                | empty                                                                                                                | revoked                                    | Session; revoke current token; repeat is safe                                                                                                                                      |
| Password change    | POST /auth/password                              | currentPassword, password                                                                                            | changed                                    | Session; user lock, hash replacement + revoke all sessions atomically; must login again                                                                                            |
| Recovery           | POST /auth/recovery                              | email                                                                                                                | unavailable                                | Public; 503, no email or reset token generated                                                                                                                                     |
| Workspace list     | GET /workspaces                                  | none                                                                                                                 | own active workspace IDs, names, roles     | Session; active membership only                                                                                                                                                    |
| Onboard            | POST /onboarding                                 | workspaceName, currency, timeZone?, workspaceType?, fullName?, language?, dateFormat?                                | workspace                                  | Session; lock user, create workspace + owner membership + manual account + categories atomically; repeat returns existing workspace                                                |
| Member list        | GET /workspaces/:wid/members                     | none                                                                                                                 | IDs, names, roles/status                   | Owner only, no personal preferences                                                                                                                                                |
| Member change      | PATCH /workspaces/:wid/members/:id               | role: editor/viewer, status: active/revoked                                                                          | membership                                 | Owner; lock workspace, recheck permission, protect owner; no invites or new users                                                                                                  |
| Accounts           | GET /workspaces/:wid/accounts[/:id]              | currency? on list                                                                                                    | account(s), openingBalanceMinor            | Active member; scoped FinancialAccount                                                                                                                                             |
| Categories         | GET /workspaces/:wid/categories                  | currency? omitted                                                                                                    | category IDs/names/kinds                   | Active member; scoped Category; read only                                                                                                                                          |
| Transactions       | GET /workspaces/:wid/transactions                | currency required; accountId?, start?, end?, search?, page?, limit?, sort?                                           | rows + count/page                          | Active member; same scoped filter for count/list, snapshot transaction; sort date_desc/date_asc, limit 1–100                                                                       |
| Transaction        | GET /workspaces/:wid/transactions/:id            | none                                                                                                                 | transaction + splits                       | Active member; scoped record                                                                                                                                                       |
| Create transaction | POST /workspaces/:wid/transactions               | id (UUID operation identity), accountId, currency, date, description, type: income/expense, amountMinor, categoryId? | transaction                                | Owner/Editor; workspace lock + membership recheck, account/category validation + insert; UUID retry returns original only for identical original input; reused different input 409 |
| Update transaction | PATCH /workspaces/:wid/transactions/:id          | version, date, description, type, amountMinor, categoryId?                                                           | transaction                                | Owner/Editor; same lock + optimistic version; account/currency/source immutable; allocated/imported/transferred/split rows reject financial editing pending corrective workflow    |
| Exclude/restore    | POST /workspaces/:wid/transactions/:id/exclusion | version, excluded boolean                                                                                            | transaction                                | Owner/Editor; atomic versioned command; linked transfer pairs and payment receipts blocked; splits retained                                                                        |
| Expense summary    | GET /workspaces/:wid/expenses/summary            | currency required, accountId?, start?, end?, search?                                                                 | incomeMinor, expenseMinor, netMinor, count | Active member; same ledger filters, excludes excluded rows; transfer neutral; BigInt aggregation, no FX                                                                            |

All mutations require exact configured Origin plus `X-EasyFinance-CSRF: 1` and JSON. Cookie SameSite=Strict; production Secure, no Domain, Path=/api/v1. GETs never mutate domain state. CORS grants only configured origin, credentials enabled. Public auth rate limiting is per IP plus normalized-email hash; process-local bounded state. Session errors 401; missing/inaccessible workspace/resource 404; forbidden role 403; validation 400; stale/conflicting writes 409; rate 429; unavailable DB/recovery 503. Authentication failure responses do not reveal account existence. Registration deliberately does not authenticate: UI proceeds to login after the same neutral response for new/existing email.

Not implemented here: accounts management after the onboarding account, imports, split replacement, transfer creation/correction, invoice/payment writes, investments, invitations/acceptance, automations, assistant persistence or notifications. Existing records retain their source/splits/transfer semantics; unsupported mutations are blocked rather than silently discarding relationships.

## Block 9B.1 contract inventory

All paths below are under `/api/v1/workspaces/:wid`. Active server membership is required; Owner/Editor mutations, Viewer reads. Existing CSRF/error conventions apply. Unknown writable fields are rejected. Financial amounts in responses are decimal minor-unit strings; item quantities/prices/rates remain decimal strings.

| Method / path                | Request                                                                                                                   | Response / boundary                                                                      |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| GET /clients                 | none                                                                                                                      | Scoped clients, including archived history                                               |
| POST /clients                | id, type, name, businessName, email, phone, address, taxId, defaultCurrency, paymentTerms, notes                          | Client; idempotent UUID creation                                                         |
| PATCH /clients/:id           | Same editable client fields without id                                                                                    | Client; historical invoice snapshots unchanged                                           |
| POST /clients/:id/archive    | archived boolean                                                                                                          | Client; history retained                                                                 |
| GET /invoices                | currency, accountId?, clientId?, start?, end?, search?, status?, page?, limit?                                            | Rows/count and currency-scoped summary; issue-date filters                               |
| POST /invoices               | id, number, clientId, accountId, currency, issuedDate, dueDate, paymentTerms, items, discount, notes, paymentInstructions | Draft; authoritative header/items calculated and saved atomically                        |
| GET /invoices/:id            | none                                                                                                                      | Scoped detail, items, derived paid/outstanding/status, allocations/payments and activity |
| PATCH /invoices/:id          | Same draft fields without id, plus version                                                                                | Draft only; optimistic version and workspace lock                                        |
| POST /invoices/:id/issue     | version                                                                                                                   | Issued document; no email or cash receipt                                                |
| POST /invoices/:id/cancel    | version                                                                                                                   | Cancelled only without allocations; no deletion/refund                                   |
| POST /invoices/:id/duplicate | id, number                                                                                                                | New draft, no receipt/history cloning                                                    |
| POST /invoices/:id/payments  | idempotencyKey, amountMinor, date, method, reference, transactionId?                                                      | Payment/allocation; atomic new receipt or compatible existing receipt reuse              |
| GET /payments/:id            | none                                                                                                                      | Scoped payment and allocations                                                           |
| GET /income/summary          | currency, accountId?, clientId?, start?, end?                                                                             | Cash received by booking date; billed/paid/outstanding/overdue by invoice issue date     |

A payment key is workspace-wide and immutable: identical retries return the original payment; changed payload/invoice/actor conflicts. Existing payment receipts may allocate their remaining amount to another compatible invoice through a new request key recorded in ActivityLog. No email delivery, refund, credit note, recurring scheduler or bank-match suggestion API is included. Account balances derive from opening balance plus non-excluded signed transactions; transfers affect individual balances but remain neutral in income/expense totals.

## Block 9B.2 contract inventory

All routes below are under `/api/v1/workspaces/:wid`, require real authentication and active membership. Owner/Editor may preview/confirm and categorize; Viewer may read history. No schema migration is planned.

| Operation        | Method / route                     | Request / response                                                                                                     | Transaction and errors                                                                                              |
| ---------------- | ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Preview CSV      | POST `/imports/preview`            | CSV text, filename, account/currency, mapping, normalization options → normalized rows, candidate matches, review hash | No writes; scoped account validation; 400 invalid format, 403 role                                                  |
| Confirm CSV      | POST `/imports`                    | Same source, UUID key, preview hash, explicit row decisions → batch and accepted count                                 | Atomic batch/ledger/audit; workspace lock; repeat key returns same result, changed key payload or stale preview 409 |
| History / result | GET `/imports`, GET `/imports/:id` | Recent scoped batches / retained decisions                                                                             | Read only; cross-workspace 404                                                                                      |
| Categorize       | PATCH `/transactions/:id/category` | Version, nullable categoryId → transaction                                                                             | Versioned category-only update; protected receipt/split/transfer 409; wrong category 400                            |

CSV is bounded to 2 MB / 500 rows; JSON transport is bounded separately. Full source is parsed again on confirmation. Existing matches can be explicitly excluded/reused or reviewed as distinct Keep Both; no existing financial record is overwritten. Category management/rule automation remains outside this slice.
