# Block 7 visual audit

Reviewed 17 November 2026 (Australia/Sydney). Supplements all six preserved block reviews. This is a responsive implementation review, not pixel-perfect or final design approval.

## References and method

The [frame index](FRAME_INDEX.md) lists the actual local SVG filenames and dimensions used. All 40 frame files were rendered locally; 39 correspond to principal screen targets and one is the standalone Aside. All 21 desktop/mobile comparison sheets were visually inspected against browser captures. No Figma MCP, external replacement artwork or generated UI image was used. The original logo, palette, SVGs and blueprint remain unchanged.

The inventory still lacks F04 desktop/mobile and F06 mobile. These targets were reviewed against existing shell/auth conventions and remain provisional. No missing reference was fabricated. Exact font identity and separate loading/error/editor/dialog exports remain unresolved.

Runtime captures use Chromium at 1440×900 and 390×844. Auth files are under `test-results/auth-layouts/`; F05–F21 files are under `test-results/block7-layouts/`. In the table, `D/M` means both `desktop-` and `mobile-` prefixes. Every protected-screen capture also has a `-viewport.png` version. Files are ignored local test artifacts, regenerated by the full browser suite.

## Interaction and responsive findings

All principal targets check document width, loaded images and browser errors. Representative F06/F09/F13/F14/F17/F20/F21 pages also passed width checks at 320×900 and 768×900. Additional `${desktop|mobile}-${320|768}-automations.png` captures document the narrow/tablet checks. Existing module suites capture review dialogs, invoice preview, splits, rule editing, valuation and sharing confirmations.

Fixed headers/composers/navigation can appear midway through a full-page screenshot because they retain the current viewport position; they are not static poster elements. Content remains scrollable above bottom navigation. Mobile filters wrap, tables become cards where implemented, financial amounts remain readable and dialogs scroll independently. An invoice editor with a million-unit price was width-checked before saving the ordinary-value journey.

Native dialog Escape/button closure returns focus to its opener. Mobile transaction close/reopen/search coverage and the six dialog regression tests remain intact. Route tests wait for headings and loading fallback removal. The Home audit locator initially omitted the button's visible arrow; correcting its accessible name fixed the test without sleeps or changing application behavior. A missing Link import during the earlier navigation edit was fixed and regressions rerun.

## Limits

No missing principal reference beyond F04 desktop/mobile and F06 mobile was found. Other interaction-state exports, typography confirmation and design-owner approval remain pending. Runtime content is deliberately longer than static artwork because of real fields, financial explanations and sample-data notices. No claim is made for exact pixel matching, screen-reader certification, other browser engines, real devices or CI execution.
